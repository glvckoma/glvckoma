## About

I grew up in Florida, live in West Virginia, and work for myself. I have a BS in Application and Web Development from Marshall University (2026) with a Game Development minor.

Most of what I build starts with reverse engineering something that was never meant to be extended. I talk to the people actually using it, dig until I find the real problem, then ship the smallest version that fixes it.
